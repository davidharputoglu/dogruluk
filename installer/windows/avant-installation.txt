Cet assistant d'installation est personnalisé :
 - Langue de l'installeur : choisissez-la sur la première page
   (français, anglais, turc, allemand, italien, espagnol, portugais,
   arabe, kazakh, ouzbek).
 - Répertoire : vous pouvez modifier le dossier de destination
   (par défaut C:\Program Files\Doğruluk).
 - Composants : application seule, fichiers d'exemple, environnement
   Python dédié (.venv), téléchargement de Python si absent.

Après installation, Doğruluk démarre un petit serveur local et ouvre
votre navigateur sur http://localhost:8000. Aucune donnée n'est envoyée
sur Internet : tout reste sur votre machine.
