## English

**Doğruluk — quote & invoice checker, all suppliers**

**Version 0.1 (frozen until the publisher explicitly requests a change)**
**Publisher: David HARPUTOGLU — assisted by AI · Contact: kasparof57@gmail.com**
**Public repository: https://github.com/davidharputoglu/dogruluk**

Doğruluk (meaning "accuracy" in Turkish) checks your supplier invoices and quotes
(Point.P or any other supplier) line by line against your negotiated price lists:

- discrepancy = **(invoiced price − agreed price) × quantity**, accumulated per line, per invoice and overall;
- items missing from the price list are set aside with the message *"I don't have the price for that"* → complete the list, automatic re-check;
- matching first **by item code**, then by description; configurable rounding tolerance (global and per supplier);
- **materials purchase summary per job site**;
- import **Excel / CSV, PDF, electronic invoice (Factur-X, UBL, CII)**;
- Excel/CSV exports of discrepancies (to request a credit note) and per-site totals;
- modern multi-theme interface: **turquoise (default)**, dark, black, customizable;
- 14 languages: French, Arabic (RTL), English, Italian, Spanish, Portuguese, Turkish, Azerbaijani, Kazakh, Kyrgyz, Uzbek, Turkmen, Tatar, Bashkir;
- integrated legal notice, privacy policy and license (pages `/mentions-legales`, `/confidentialite`, `/licence` + files `LICENSE` / `NOTICE`).

### Quick start

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# http://localhost:8000
```

Windows: double-click `scripts/run_windows.bat` (requires Python 3.10+).

Express Linux/RPi installation:

```bash
sudo bash scripts/install.sh        # systemd service + port 8000
```

Docker (all platforms, including Portainer/Podman):

```bash
docker run -d --name dogruluk -p 8000:8000 \
  -v dogruluk_data:/data -v dogruluk_exports:/exports \
  ghcr.io/davidharputoglu/dogruluk:0.1
```

### Persistent settings ("Settings" page)

Display name, language, default tolerance, currency, publisher/contact — stored in
the local SQLite database (`data/verif.db`), they take precedence over environment
variables. The theme is remembered browser-side (localStorage + cookie).

Technical environment variables: `VDF_APP_NAME`, `VDF_VERSION`, `VDF_EDITION`,
`VDF_TOLERANCE`, `VDF_LANG`, `VDF_HOST`, `VDF_PORT`, `VDF_DATA_DIR`,
`VDF_EXPORT_DIR`, `VDF_AUTHOR_NAME`, `VDF_AUTHOR_EMAIL`.
